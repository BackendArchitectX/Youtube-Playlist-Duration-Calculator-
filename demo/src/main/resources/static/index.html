YouTube Playlist Length

Find the Youtube Playlist Length and Youtube Music Playlist Length in a Single click. Get a fast response, simple & free to use.

Note:
  • This tool only counts public videos. We cannot include hidden or deleted videos because YouTube does not share that information in Official API.
  • You don't have to calculate the whole playlist. You can measure just a specific section using the "From" and "To" boxes.
  • Leave "From" empty? We start at the very first video.
  • Leave "To" empty? We count all the way to the last video.
  • Example: If you want to check the length of videos 11 through 40, just type 11 in the "From" box and 40 in the "To" box.
