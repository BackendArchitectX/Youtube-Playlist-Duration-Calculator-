YouTube Playlist Length

Calculate total duration and watch times at different speeds for any YouTube or YouTube Music playlist.

How it works
  • Only public videos are counted (YouTube API limitation)
  • Specify a range to calculate only a section of the playlist
  • Leave "From" empty to start from the first video
  • Leave "To" empty to include all videos until the end
